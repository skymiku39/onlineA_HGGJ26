# Break the Loop — 勢力真源

## 核心分工

本故事的城外壓力分成三層，但只有兩層是主要可寫、可破解、可被公主實際處理的陣營。

| 層級 | 敘事身份 | 是否主視角陣營 | 功能 |
|---|---|---|---|
| 鄰國軍事威嚇 | 真實外患 | 否 | 給國王與軍方真正壓力，讓備戰與封鎖有合理性 |
| 宰相私軍／叛軍 | 宰相可操控的城外代理力量 | 是 | 執行密信、糧倉、密道、恐嚇、接應與假襲擊 |
| 被動員暴民 | 被飢荒與謠言推動的城內群體 | 是 | 造成內亂、堵塞軍方、替宰相敘事開門 |

關鍵原則：國王面對的威嚇是真的；宰相的手筆在於污染情報、加速時機、操控代理人，讓每個防衛決策都看起來像壓迫人民。

---

## 鄰國軍事威嚇

鄰國不是終章要細寫的主視角反派，而是王國正在承受的真實戰略壓力。

- 鄰國確實在集結軍隊，也確實覬覦王國土地、魔法資源與防線破口。
- 國王收到的「鄰國準備入侵」情報不是完全假的，所以他的備戰、徵用、封鎖與城防壓力有現實基礎。
- 宰相利用這份真實壓力，把「必要備戰」推成「民眾看不懂的壓迫」。
- 宰相透過邊境中介、假襲擊、密信與私軍活動，讓鄰國威嚇看起來比實際更混亂、更迫近、更難澄清。
- 賽拉斯能察覺邊境與斥候線異常，但缺少足以直接指控宰相的政治證據。

寫作底線：國王不是被一個空洞謠言騙倒，而是在真實外患與被污染的內部情報中做錯判斷。

## 宰相私軍／叛軍

### 定位

宰相私軍／叛軍是莫里昂可直接調動的城外與邊境代理力量。它不是鄰國正規軍，而是讓「外患」與「內亂」互相接上的中間層。

### 來源

- 宰相家臣與封地護衛。
- 被收買的傭兵與退伍兵。
- 邊境走私線、商隊護衛與情報掮客。
- 被安插在補給、城防、道路維修中的人。
- 對國王改革失去利益的舊貴族殘黨。

### 表面身份

- 護衛、商隊、救濟運輸隊。
- 災後道路維修與城牆維護人員。
- 邊境情報人員與臨時巡防人手。
- 保護糧倉或押送物資的「合法」私兵。
- 王室外出路線中的代理侍衛、門禁文書與外圍眼線。

### 實際功能

- 維持密道與城外接應點。
- 護送密信、糧食、藥材與賄賂。
- 恐嚇證人，讓下城區居民不敢說出真相。
- 製造假襲擊，讓國王與賽拉斯被迫把人力壓到錯的地方。
- 在 B 線撤換或放遠公主正常外出保護，讓門禁、名冊與展示路線變成陷阱。
- 切斷忠誠部隊路線，讓賽拉斯永遠在救火。
- 在終章前接應宰相潛逃，或在城破日協助內應開門。

### 章節用途

| 章節 | 呈現方式 |
|---|---|
| 序章 | 只留下城破速度不合理、內應開門、邊境斥候異常的結果 |
| 第一章 | 作為宰相能提前掌握路線與滅口的隱形手 |
| 第二章 | 透過糧倉、密道、黑衣人、下城區路線露出輪廓 |
| 第三章 | 成為公主急躁單線出手時的反噬來源，能迅速轉移證據或滅口 |
| 終章 | 被賽拉斯切斷補給與接應，失去暴民掩護後被瓮城收網 |

## 被動員暴民

### 定位

被動員暴民不是邪惡群體，而是真實苦難被導向錯誤出口後形成的群體壓力。玩家與公主必須同時看見兩件事：民怨是真的，暴力方向是被設計的。

### 群體分層

- 飢餓者：只想拿到糧食與藥，最容易被「敵軍會帶來食物」煽動。
- 失業工人與搬運者：熟悉路線、倉庫與城門，是謠言擴散與堵路的關鍵。
- 青年激進者：相信王室永遠不會救人，容易被私軍利用成衝突前排。
- 照護者：不想鬧事，但家中病人與孩子讓他們無法再等。
- 中間派：知道事情不對，卻害怕宰相的人、巡邏兵與鄰里報復。
- 布魯諾一線：能把個人傷痛轉成公開證詞，是終章拆解暴民敘事的入口。

### 被宰相利用的功能

- 堵住忠誠騎士與救濟隊的路線。
- 破壞或打開城門，讓內應有機會接上外部力量。
- 散播「國王藏糧」「敵國會給糧」「公主只是來作秀」等敘事。
- 讓王室的任何強硬措施都看起來像暴政。
- 逼賽拉斯把軍力用在維持秩序，而不是追查宰相。

### 章節用途

| 章節 | 呈現方式 |
|---|---|
| 第二章 | 讓公主第一次真正看見下城區的痛苦不是謠言 |
| 第三章 | 公主若只處理表面暴亂，會害死重要的人並讓敘事反噬 |
| 終章 | 靠親送糧食、地方證詞、布魯諾轉向與可核對帳目拆掉動員基礎 |

## 兩股力量的差異

| 對照 | 宰相私軍／叛軍 | 被動員暴民 |
|---|---|---|
| 是否知道真相 | 多半知道自己在替宰相做事 | 多半不知道自己被利用 |
| 主要動力 | 利益、忠誠、賄賂、舊貴族秩序 | 飢餓、恐懼、失親、無力感 |
| 公主的處理方式 | 證據、封鎖、軍事切斷、逮捕 | 糧食、信任、公開查核、證詞 |
| 終章收束 | 瓮城與密道收網 | 布魯諾與下城區敘事翻轉 |
| 道德定位 | 敵對執行者 | 被操縱的受害者與風險源 |

## 寫作提醒

- 不要把暴民寫成單一嗜血群體；他們的痛苦必須成立。
- 不要把國王寫成只被假威嚇欺騙；外患本身是真的。
- 不要把宰相私軍寫成鄰國軍隊；它是內外勾連的代理層。
- 終章要用不同方法解兩股力量：私軍靠軍事與證據切斷，暴民靠糧食、查核與信任拆解。
