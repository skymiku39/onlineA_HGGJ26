# 公主艾蓮娜——知識積累與成長弧線

> 本文件追蹤公主在每一輪迴中學到了什麼，包括客觀情報、認知轉變與習得的能力。
> 重點在於**她的視角如何改變**，而不只是「她知道了什麼事實」。
> 本文件追蹤公主內在認知；公主改變後，世界、角色與勢力如何因應，請看 `canon/00_Loop_Response_Matrix.md`。
> 本文件**不是第二份劇情大綱**；詳細事件順序與場景節拍請回看 `LOOP_OUTLINE.md` 與 `scenario_*_outline.md`。

---

## 使用原則

- 這份文件只回答三件事：**她此時知道什麼、她還誤判什麼、因此下一輪會改怎麼做**。
- 這份文件不回答「別人怎麼因應她的變化」；該問題的真源是 `canon/00_Loop_Response_Matrix.md`。
- 若要查精確事件順序、場景節拍或台詞依據，請回看 `LOOP_OUTLINE.md` 與對應 `scenario_*_outline.md`。
- 若要查角色本質與說話方式，請回看 `dialogic/story_docs/canon/00_Characters.md` 與 `characters/princess_elena.md`。

## 章節級認知推進

### 第一章：信任的盲區

| 項目 | 內容 |
|---|---|
| 她最初的誤判 | 只要找到一個願意保護自己的大人，就有機會活下去 |
| 這章打掉的濾鏡 | 溫柔不等於安全；王權不等於即時保護；賽拉斯的冷也不等於背叛 |
| 這章留下的核心能力 | 觀察表情、記住毒茶氣味、把碎片記憶跨輪連接 |

### 第二章：無形的鳥籠

| 項目 | 內容 |
|---|---|
| 她最初的誤判 | 只要繞過宰相正面、直接去看民間現場，就能找到沒有被污染的答案 |
| 這章打掉的濾鏡 | 苦難是真的，但敘事會被安排；女僕的善意也可能被網利用；監視盯的是異常與視線 |
| 這章留下的核心能力 | 偽裝順從、讀敘事而不只讀人、改用口頭線索與身體走線 |

### 第三章：崩解的穹頂

| 項目 | 內容 |
|---|---|
| 她最初的誤判 | 只要比對方早一步知道真相，就有機會救下關鍵證人或直接翻盤 |
| 這章打掉的濾鏡 | 技術體系內也有內鬼；匿名匯報不等於安全；父王知道真相也不等於局面立刻可救 |
| 這章留下的核心能力 | 默背節點、辨識體制性清場、理解「同步揭露」比「提早揭露」更重要 |

### 終章：最終輪迴

| 項目 | 內容 |
|---|---|
| 她不再做什麼 | 不再追求先證明自己是對的，不再單獨扛著真相到處撞門 |
| 她真正會做什麼 | 分配時機、分配信任、分配風險，讓正確的人在同一瞬間就位 |
| 她最終完成的事 | 從被保護的對象，變成重新接上所有斷橋的人 |

## 最終輪迴前，她已經知道的事

### 關於宰相

- 他最可怕的地方不是單一暗殺手段，而是能替每個人安排一個「看似合理但其實錯誤」的理解版本。
- 他的控制橫跨毒茶、監視、民意敘事、財政維護鏈與城牆密道。
- 只要有人太早知道某條真相，他就會先清掉那個知情者。
- 終章擊敗他的關鍵不是比他更早知道一件事，而是把他刻意隔開的軍人、技術官、平民證詞與王權合法性重新接到同一時間點。
- C-2 高塔最後一夜，她親眼看見鄰國軍隊與宰相私軍／叛軍代理層接上，才把「真實外患」與「宰相代理層」的關係完全分開。

### 關於父王與賽拉斯

- 父王不是不愛她，而是把沉默當成保護。
- 賽拉斯不是冷血，而是被密令與職責困住。
- 光靠情感理解兩人還不夠；她必須把他們放進正確的時間表裡，這份理解才能轉成有效行動。

### 關於下城區與布魯諾

- 苦難是真實的，所以平民的怒氣不是誤會，而是被錯誤引導。
- 布魯諾不會被空話打動；只有承認傷口、給出可核對線索與先送到場的物資，才有翻轉空間。

### 關於自己

- 她不是天生的布局者，而是一次次死後學會修正的人。
- 她最終能成為執棋者，不是因為情緒變少，而是因為知道情緒該放在什麼時候。

## 一句話總結

公主真正累積起來的，不只是情報，而是**讀世界的方法**：先看誰在說話，再看誰不能說話；先看真相在哪裡，再看誰會因為太早知道而死；最後才決定，這一次該讓誰先知道。
