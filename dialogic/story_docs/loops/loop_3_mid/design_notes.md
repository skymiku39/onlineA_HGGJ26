# Loop 3 / 中期輪迴 — 設計筆記

## 反轉編號與核心命題

**反轉 4：技術真相也會被程序吃掉。**

公主已經非常接近真相：她知道宰相是敵人、知道民怨被操控、知道物理城防有破口。Loop 3 的任務不是再證明她聰明，而是讓她看見：就算找到正確技術人員與正確問題，只要沒有保護、程序與同步，真相仍會害死知情者。

## 公主的進場心態

- 帶著 Loop 1 和 Loop 2 的教訓：溫柔大人不可靠，順利外出也可能是陷阱。
- 她已經不再只讀人，而開始讀流程、日誌、維護週期與清場令。
- 核心偏見：「只要我比他們早一步知道，就能救下關鍵證人。」
- 醒來內心獨白應該冷而短：物理破口已確認，現在輪到魔法陣。

## 目標情緒曲線

```
冰冷（醒來）→ 精準學習（達爾課堂）→ 看見內鬼（副手與日誌）→ 工作室清場（證人死在眼前）→ 提前警告仍失敗 → 交牌父王 → 高塔與主動選擇
```

情緒最高點：工作室中達爾與公主終於對上腐蝕節點。
情緒最低點：C-2 高塔裡，她理解父王相信她，但王權單獨接不住全局。

## 失敗觸發邏輯

- C-0：公主看見技術真相，但工作室仍在副手與維護鏈掌控中，達爾與公主被近身清場。
- C-1：公主提早警告達爾，但「有人知道了」本身觸發清場，匿名匯報也被程序污染。
- C-2：公主把全局交給父王，父王以父親身分相信她，卻以國王身分先隔離她；宰相轉入潛逃與拖延。

## 現行定位

- 達爾是宮廷陣防老工匠／技術負責人，仍在體制內工作。
- 公主以王室教育、城防旁聽與正確技術問題建立入口。
- 核心危險是：找到證人後，證人仍會被程序、近身副手與敘事翻轉吞掉。
- 第三章教訓是：真相、證人、程序與保護必須同步。

## 設計備忘

- 達爾的技術門檻要明顯。他尊重公主，不是因為她是王女，而是因為她問對問題。
- 副手不要演成明顯壞人；他越像正常流程的一部分，越可怕。
- 財政署清場令是關鍵伏筆：它看起來完全正規，所以腐蝕才藏得住。
- C-2 的父王不是冷血。他最痛的地方是相信女兒，卻仍親手把她放進高塔。
- 第三章結尾要把公主推向終章的核心理解：不是「我知道了」，而是「誰必須在什麼時候一起知道」。
