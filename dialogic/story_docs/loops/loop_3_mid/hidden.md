# Loop 3 / 中期輪迴 — 暗線設計

> Loop 3 的暗線核心：**技術真相、維護鏈與出手時機**。
> 公主在這個迴圈中取得最接近全局的情報，但她每次都把真相放到錯誤的位置，導致知情者被清場或王權保護變成隔離。

---

## 調查事件

### 事件 K：以學生身分接近達爾

**觸發：** 擁有 `intel_dal_magic_basics`。

公主不是靠王女身分命令達爾交出核心，而是延續 B-1 建立的「對魔法防護著迷」人設，走王室教育、城防沿革旁聽與公開卷宗調閱的程序。

| 步驟 | 明線 | 暗線 |
|---|---|---|
| 問對術語 | 公主問出比上次精準的問題 | 達爾第一次確認她不是背台詞 |
| 外層巡視 | 達爾帶她走可申請的巡視路線 | 陣核仍受管制，公主不能自由進入 |
| 兩個月默背 | 她不帶紙筆，只記節點、導流與接縫 | 宰相放任她在可監視範圍內觸雷 |
| 維護日誌 | 她對照正常週期與清場令 | 財政署名義正當，正因如此難以被懷疑 |

**獲得情報：** `intel_magic_array_mnemonic`

---

### 事件 L：助手與維護鏈

達爾身邊的副手不是高調反派，而是程序的一部分。他的危險在於「總是剛好」：

| 行為 | 表面解釋 | 真實作用 |
|---|---|---|
| 補充達爾的話 | 幫老師節省時間 | 把公主問題帶離腐蝕節點 |
| 端茶與整理工具 | 工作室日常 | 保持近身暗殺與布置現場能力 |
| 提醒清場時程 | 尊重流程 | 讓真正腐蝕發生在無外人在場的時段 |
| 記錄公主問題 | 教學紀錄 | 向宰相回報她看見了哪裡 |

**獲得情報：** `intel_array_handed_clerk`

---

### 事件 M：工作室清場（C-0）

當達爾與公主終於把腐蝕節點、維護日誌與財政署清場令對上時，副手立刻啟動清場。

| 事件 | 公主帶走的認知 |
|---|---|
| 達爾誤飲毒茶 | 毒茶不是只存在寢宮；任何被宰相控制的近身流程都能出現 |
| 公主被近身武器格殺 | 宰相不需要親自到場，現場也能被布置成技術事故 |
| 工作室被嫁禍 | 只看見真相還不夠，還必須保護能證明真相的人 |

**獲得情報：** `intel_array_structural_passage`、`intel_chancellor_treason`

---

### 事件 N：提前警告仍然失敗（C-1）

公主第二次嘗試時，以為只要比副手快一步告訴達爾，就能救下他。真正的問題不是名字暴露，而是「有人知道了」本身就會觸發清場。

| 公主做法 | 宰相一方如何反制 |
|---|---|
| 私下警告達爾 | 維護鏈判定達爾可能失控 |
| 要求匿名匯報 | 程序本身已被污染，匿名不等於安全 |
| 獨自走向陣區 | 正常管制攔下她，再被剪成擅闖與干預 |
| 父王保護性軟禁 | 善意隔離被宰相利用成毒殺窗口 |

**獲得情報：** `intel_narrative_flip`、`intel_king_defense_line`

## 關鍵設計：公主的錯誤解讀

Loop 3 的情報大多正確，錯的是出手方式：

| 正確情報 | 公主當輪做錯的地方 | 終章修正 |
|---|---|---|
| 魔法陣腐蝕可定位 | C-0 只和達爾在工作室確認 | 先讓賽拉斯控場，再讓達爾可複驗 |
| 副手是近身危險 | C-1 只提醒達爾本人 | 先切掉副手與清場流程 |
| 父王會相信她 | C-2 直接把全局交給王權 | 同步兵、民、術、證，讓王權能公開採信 |
| 宰相會潛逃 | C-2 提醒後沒有同步堵路 | 終章先標定密道與私軍接應點 |

## NPC 在 Loop 3 時段的隱藏行為

| NPC | Day 1-30 | Day 30-90 | Day 90-150 |
|---|---|---|---|
| **國王** | 密室研判，外患壓力加重 | 開始懷疑宰相，但缺乏可公開採信的證據 | C-2 相信公主，卻以保護名義把她隔離 |
| **宰相** | 例行偽裝，觀察公主轉向技術線 | 透過副手與維護鏈記錄她的問題 | 觸發工作室清場、陣區敘事翻轉與潛逃準備 |
| **賽拉斯** | 夜間訓練民兵 | 城外交手頻率倍增，負傷 | 若未收服，仍被調令與軍務壓住 |
| **莉娜** | 維持寢宮日常 | 察覺公主變得更安靜 | C-2 高塔段被切斷聯絡 |
| **布魯諾** | 仍在下城區壓力中 | 被宰相代理層持續推動 | 若無終章同步，民怨仍會被利用 |
| **達爾** | 以技術門檻測公主 | 開始承認她是學生 | 若沒有保護機制，會成為被清場的單點證人 |
