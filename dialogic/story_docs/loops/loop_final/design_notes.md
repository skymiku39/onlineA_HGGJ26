# 最終輪迴 — 設計筆記

## 核心命題

**所有濾鏡剝落。**

公主帶著多次死亡的記憶和完整真相覺醒。她不再被任何單一濾鏡束縛：不再天真地依附大人，不再把民怨當成單純敵意，也不再以為自己一個人知道真相就能救人。她成為領導者，是因為她終於懂得分配時機、信任與風險。

## 公主的進場心態

- 帶著所有迴圈的教訓和所有情報。
- 放下對父王的單純怨恨，但不美化他的錯誤。
- 理解孤軍奮戰的代價：一個人知道真相是不夠的。
- 醒來內心獨白：「順序。先讓能行動的人知道能查的事，再讓真相被公開接住。」

## 目標情緒曲線

```
鋼鐵般的決意（醒來）→ 重新取得賽拉斯信任 → 下城區查核與心酸 → 達爾安全接入 → 朝堂同步揭露 → 修復與收網 → 破曉釋然
```

情緒最高點：朝堂上兵、民、術、證同時落地，宰相再也不能切割敘事。
情緒最低點：國王承認自己低估女兒，並理解保護也曾造成傷害。

## 公主變化與世界因應

| 面向 | 因應設計 |
|---|---|
| 公主帶入的變化 | 她不再單線突破，而是分配時機、信任與風險。 |
| 角色初始反應 | 賽拉斯、莉娜、布魯諾、達爾、國王都不記得前輪，因此先震驚、遲疑，再被可核對資訊說服。 |

## 設計備忘

- 收服賽拉斯的場景不是展示情報，而是用他能核對的軍務裂縫讓他願意承擔風險。
- 布魯諾的關鍵在「歸還」：公主不是施捨糧食，而是把被截斷的救濟路徑重新接上。
- 達爾線必須先保護人，再談修復；終章不要把他放回工作室清場的節奏。
- 揭露宰相時，莫里昂可以短暫欣賞公主，但不能被洗白。他輸的是同步證據，不是突然變笨。
- 真結局的核心情緒不是凱旋，而是釋然。代價已經在前面輪迴付過，破曉應安靜而有重量。
- 口頭密令用公開宣誓收束：賽拉斯承認那道命令終止，公主也被公開承認為能承擔真相的人。
