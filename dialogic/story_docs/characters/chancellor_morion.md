# 宰相 莫里昂（Chancellor Morion）

| 項目 | 說明 |
|---|---|
| 年齡 | 52 歲 |
| 勢力歸屬 | 敵意貴族（叛國者） |
| 角色定位 | 真正的幕後黑手。玩家前期的「假盟友」 |
| 口癖/語氣 | 永遠溫和有禮，用「殿下」開頭。越危險的話說得越輕柔 |
| 核心衝突 | 國王的改革削減了貴族特權。與敵國密約：裡應外合攻破王城，事後保留封地與財富 |

## 表情組

`default`（慈祥微笑）、`concerned`（假裝擔憂）、`cold`（露出真面目，僅最終輪迴）、`smile`（笑）

## 目標

**個人目標（角色主觀）：**

- 保住被國王改革削弱的封地、財富與舊貴族特權。
- 讓王國在可控的方式下崩壞，自己以「最後能收拾局面的人」接管殘局。
- 與鄰國密約成功後，以新政權總督身分保留權力與利益。

**劇情目標（故事功能）：**

- 作為所有誤判的設計者，讓公主每次都拿到「合理但不完整」的答案。
- 把真實外患、真實民怨、真實防衛需求加工成錯誤敘事。
- 逼迫公主學會不能單線突破，必須同時處理兵、民、術、證。

## 每輪對公主變化的反應

> 莫里昂不能寫成全知。他的可怕來自推理管道與控制習慣：項鍊是否配戴、莉娜與侍從回報、路線異常、文書查詢、線人、私軍、維護鏈。每一輪他都只知道「公主在這一輪露出的異常」，不知道她曾經死過。

| 輪次 | 他掌握的訊號 | 他的推理 | 因應與演出邊界 |
|---|---|---|---|
| LOOP 0 | 無需掌握；局已完成。 | 公主仍是無知棋子。 | 不出場，讓他的缺席變成威脅。 |
| A-0 | 公主驚慌、依賴、接受項鍊。 | 她需要一個大人接住恐懼。 | 使用預設溫柔、偽帳本、人證與毒茶，不需加碼。 |
| A-1 | 項鍊被拒、庭院反應不自然、賽拉斯被問到邊緣。 | 公主開始不受日常控制，可能有人影響她。 | 提前孤立、調離賽拉斯、收緊門禁；他不知道輪迴。 |
| A-2 | 公主越過他接近父王。 | 她正在找上游真相，但證據不足。 | 改用間接毒殺與敘事先手，不必親自動手。 |
| B-0 | 公主透過莉娜往下城區走。 | 她把調查方向轉向民間與近身侍女，還以為莉娜能提供乾淨通道。 | 不公開批准；暗中撤換正常暗衛、打開門禁與名冊，順勢把善意通道變成定位通道。 |

| B-2 | 線人回報她從被安排的展示路線中失去定位，靠近密道、糧倉或異常牆線。 | 她碰到物理破口，但未必理解全局。 | 透過私軍與線人轉移、封堵、製造反噬；不能憑空知道她全部意圖，只能處理路線異常。 |
| C-0 | 維護鏈回報公主問到節點與紀錄。 | 她開始具備技術理解，威脅升級。 | 啟動助手近身控制、毒茶、清場與嫁禍。 |
| C-1 | 有人開始查核維護鏈。 | 不需知道名字，只需知道「有人知道了」。 | 標準化滅口與敘事翻轉，把查核剪成破壞。 |
| C-2 | 王權開始收束證據。 | 公主已逼近終局，但同步尚未完成。 | 轉入潛逃、轉移證據、等待城破與外部壓力。 |

## 關鍵設計

莫里昂的可怕，不在於他做了多少壞事，而在於他**設計每個人會怎麼理解世界**。  
他的台詞永遠不直接說謊——他只是省略真相、安排視角、控制時機。例如「陛下已經派人處理了」這句本身是真的，但他確保每個人都只看見那個對自己最有利的部分。

玩家在獲得情報後重讀他的話，應該會發現：每一句都不是單純的偽裝，而是**把別人往錯誤結論上推一小步**。

## 莫里昂的真正策略目標

莫里昂要的不是單純亡國，也不是單純刺殺王室。

他要的是一個**可控的崩壞**：

- 國王背負暴政之名，失去民心卻又來不及澄清。
- 平民在飢餓中被推到足以替他打開城門，但又不至於太早失控。
- 軍方被外敵與緊急狀況拖住，沒有餘力回頭清查內部。
- 私軍維持密道、糧倉與假襲擊，讓外患看起來更近，讓國王與賽拉斯被迫救錯火。
- 公主永遠停在「差一點就懂了」的階段，無法真正成為變數。
- 等王國以最難挽回的方式崩壞後，他再以倖存的權臣身分接管秩序與利益。

他的核心欲望不是混亂，而是：**讓別人付出代價，再由自己接收剩下的一切。**

## 五層操控模型

### 1. 對國王：拖慢決斷

莫里昂不急著和國王正面對決，因為他知道國王真正可怕的地方是「一旦確信叛徒是誰，就會立刻轉入戰時模式」。

所以他對國王的策略是：

- 讓每個異常都看起來像行政失誤，而不是叛國。
- 讓每個民怨都像是備戰副作用，而不是有人刻意放大。
- 讓每個延誤都有一個體制內、可再觀察的理由。
- 讓國王始終處在「事情不對，但證據還不夠」的狀態。

換句話說，他不是在擊敗國王，而是在**拖慢國王把猜測變成命令的那一刻**。

### 2. 對公主：困在錯誤答案裡

莫里昂不把公主當成有權力的人，而是把她當成**最適合被塑造成錯誤敘事容器的人**。

他對公主的策略是：

- 在她最無助的時候，讓自己看起來像唯一願意聽她說話的大人。
- 給她看到的每一條線索都帶有真實成分，讓她的誤判顯得合理。
- 當她開始成長，就不斷把她推向「只差一點點就會死」的局面。
- 不急著直接除掉她，而是先利用她的無知、同情與急躁，讓她自己走進死局。

因此，公主每輪的失敗都不是因為她笨，而是因為莫里昂一直在**替她預先布置一個最容易相信的錯誤答案**。

### 3. 對平民：把真苦難導向假敵人

莫里昂最厲害的地方，不是憑空捏造謊言，而是把真實的痛苦導向他要的方向。

他對平民的策略是：

- 截留原本要發下去的救濟糧。
- 讓重稅、徵兵、藥材短缺這些真實痛苦集中出現。
- 再把這些痛苦重新命名成「國王的暴政」。
- 給下城區一個延後兌現、卻足以撐住怒火的希望：敵軍會帶來糧食。

也就是說，他不是先造謠再找證據，而是先製造痛苦的表象，再把敘事權拿走。

### 4. 對軍方：把最危險的人固定在錯的戰場

莫里昂知道賽拉斯的能力、忠誠與執行力都很危險，所以他不先正面殺掉賽拉斯，而是先讓他永遠忙在「最急、但不是最核心」的地方。

他對軍方的策略是：

- 讓邊境、斥候、巡邏、調防永遠處於高壓狀態。
- 讓賽拉斯忙著救火，而不是追查誰在放火。
- 等到局勢接近臨界點，再把賽拉斯調離王城。
- 即使賽拉斯察覺不對，也讓他沒有足夠證據違抗命令。

莫里昂不是削弱賽拉斯的能力，而是削弱他**把能力用在正確地方的機會**。

### 5. 對城外：用私軍把真外患接成內亂

莫里昂不是只靠鄰國。他真正可怕的地方，是在鄰國正規軍抵達以前，先用自己的代理力量把城內打鬆。

他的宰相私軍／叛軍包含：

- 封地家臣與私人護衛。
- 被收買的傭兵、退伍兵與走私線。
- 偽裝成商隊、救濟運輸、道路維修與邊境情報人員的人。
- 被安插在糧倉、補給、城防與密道維護上的經手人。

這支力量的功能不是正面攻城，而是**讓別人以為攻城即將發生、讓城自己先裂開**：護送密信、維持密道、恐嚇證人、製造假襲擊、接應潛逃，並在終局前把外敵、暴民與城防破口接到同一個時間點。

## 莫里昂最擅長的三件事

### 1. 給每個人一個不同版本的現實

- 對公主，他是溫柔的保護者。
- 對國王，他是疲於善後的老臣。
- 對平民，他是唯一理解苦難的高位者。
- 對下屬，他是永遠不失控的秩序來源。

他不需要所有人相信同一套說法。  
他只需要每個人都相信**最適合自己去相信的那一套**。

### 2. 拆掉關鍵人物之間的橋

莫里昂的真正戰略不是殺光所有人，而是讓本來能聯手的人始終聯不起來。

- 國王不知道公主已經能理解真相。
- 公主不知道父王到底在承受什麼。
- 平民不相信王室還留有善意。
- 賽拉斯沒有餘力把軍事線和內政線接起來。
- 達爾活著，卻說不出足以立刻翻盤的完整證詞。

他像是在拆橋，而不是只在路上設陷阱。

### 3. 把自己放在「最後還能收拾局面的人」位置上

莫里昂不是那種喜歡站在台前大笑的反派。  
他的理想位置，是所有人都已經精疲力竭、互不信任、局面全面失控時，自己還能穿著乾淨的袍子說：

「現在，只能由臣來處理了。」

## 各章策略節奏

### 第一章：把公主困在錯誤的保護感裡

- 核心做法：成為她最像盟友的人。
- 目的：讓她親手把自己送進宰相設計的死局。
- 成果：她開始懷疑，但仍來不及脫離他的節奏。

### 第二章：讓她看見真苦難，卻找不到真源頭

- 核心做法：讓苦難真實存在，但把理解方向全部帶偏。
- 目的：讓公主以為自己已經接近真相，實際上只是在宰相暗中打開、撤換保護後允許的視線內移動。
- 成果：她開始學會偽裝，但也更加清楚自己活在監視網裡。

### 第三章：容許她逼近真相，再在臨門一腳翻桌

- 核心做法：不怕她知道片段真相，怕的是她把片段連成完整行動。
- 目的：讓她死在最接近答案的地方，並把錯誤理解推到極限。
- 成果：她終於懂得單線突破永遠會輸，必須改成多線同時落地。

### 終章：他第一次失敗的原因

莫里昂在終章會輸，不是因為他突然變笨，而是因為公主第一次做了他最不想看到的事：

- 不再單獨行動。
- 不再只追一條線。
- 不再只想證明誰是壞人。
- 而是同時修正兵、民、術、證四條線。

他過去能贏，是因為每個人都各自只看到一部分。  
他最後會輸，是因為公主第一次把那些被他拆散的人、證據與時機重新接了回來。
