# 公主 艾蓮娜（Princess Elena）

| 項目 | 說明 |
|---|---|
| 年齡 | 17 歲 |
| 勢力歸屬 | 王室（但實質上不屬於任何勢力，是所有勢力的棋子） |
| 角色定位 | 玩家角色。從無知的籠中鳥，到看透一切的破局者 |
| 口癖/語氣 | 初期：天真、疑問句多。後期：冷靜、陳述句，偶爾帶著輪迴疲憊的蒼涼 |
| 核心衝突 | 她是這座城堡裡唯一「什麼都不知道」的人——而這份無知，是所有人刻意維護的 |

## 表情組

`default`（微笑）、`sad`（哀傷）、`shocked`（驚愕）、`angry`（憤怒）、`determined`（堅定）、`hollow`（空洞，多次輪迴後）、`cold`（冷靜）、`confused`（困惑）

## 目標

**個人目標（角色主觀）：**

- 初期：活下來，弄懂自己為什麼會死、誰能相信。
- 中期：保護身邊的人，阻止下城區、賽拉斯、達爾與父王繼續被誤解害死。
- 終章：讓所有人不再靠犧牲與沉默苟活，讓王國在真相被看見的狀態下活下來。

**劇情目標（故事功能）：**

- 作為玩家的認知載體，從無知、恐懼、誤判一路成長到能統籌全局。
- 把被宰相拆散的兵、民、術、證重新接回同一張時間表。
- 在終章證明她不是被保護的花瓶，而是能承擔王國的繼承者。

## 三層目標解析

**表層目標（她自己知道的）**

活下來，弄懂誰殺了她、為什麼，找到能阻止亡國的方法。每一輪醒來，問題的形狀都不一樣：一開始是「誰」，後來是「怎麼辦」，最後才是「現在」。

**核心策略（她真正在操作的）**

每一輪死亡都在替她修正一個誤讀：從依賴到觀察、從觀察到偽裝、從偽裝到滲透、從滲透到精確部署。她在學習如何在不被看見的情況下讓更多人看見真相。她的成長不是變聰明，而是每次死後都多知道一件「這樣做只會死得更快」的事，然後把那件事從選項裡去掉。

**本質欲望（她從不說出口的）**

她不只想打贏。她想讓每一個因沉默而受苦的人——父王、賽拉斯、莉娜、達爾、布魯諾——不再需要替別人的秘密付出代價。她最深的渴望是：這座王國不要再靠犧牲誰的無知或沉默來維持下去。

## 每輪對公主變化的反應

> 公主的變化不是「越來越聰明」這麼簡單，而是每次死亡後換一種自我保護方式。寫她時要讓玩家感覺：她每一輪的冷靜，都是上一輪疼痛留下的形狀。

| 輪次 | 自我保護姿態 | 她如何誤讀自己 | 可寫演出 |
|---|---|---|---|
| LOOP 0 | 等待被救。 | 以為無知是被保護的狀態。 | 問句多，先看門、再看窗，最後看賽拉斯。 |
| A-0 | 抓住最像答案的大人。 | 以為自己是在求助，其實是在把判斷交出去。 | 面對宰相時放鬆得太快，喝茶前仍想相信。 |
| A-1 | 開始觀察他人反應。 | 以為只要看懂別人，就能不被看懂。 | 問題變短，眼神停留變多，但還不會藏住停留。 |
| A-2 | 直衝父王與權力中心。 | 以為最高權力能直接等於安全。 | 說話硬起來，像把恐懼壓成命令。 |
| B-0 | 尋找宮牆外的真相。 | 以為莉娜知道一條乾淨舊路，不知道以前的外出都有暗衛、清場與預排路線；這次順利是宰相放行。 | 對莉娜溫柔，卻沒有看見莉娜也正在害怕；她會把「太順」誤讀成「可行」。 |
| B-1 | 偽裝成宰相期待的公主。 | 以為自己借用的是正常王室流程，其實門禁、名冊與護衛已被宰相暗中改寫。 | 嘴上柔順，內心獨白冷靜到近乎分裂；看見每一枚正常印章時都更不安。 |
| B-2 | 不再交出視線，改用身體記路。 | 以為沿同一路數更大膽偏離，就能短暫脫離整張網。 | 步伐變慢，眼睛不停留太久，記憶靠觸感與方位；脫身不是逃家，是利用陷阱反走陷阱。 |
| C-0 | 逼自己成為精準學生。 | 以為問對問題就能保住答案。 | 不寫筆記，只默背；越害怕越專注。 |
| C-1 | 提前告知並嘗試匿名化。 | 以為保護名字就能保護人。 | 說明時極克制，像怕多一個字就害死達爾。 |
| C-2 | 一次交牌給父王，並在高塔半年裡看見民、兵、術各線繼續崩壞；城破日親眼看見鄰國軍隊與宰相私軍接上。 | 以為完整真相交給正確的人就夠了，後來理解抓出反派不等於修好系統，外患、私軍與暴民必須拆開處理。 | 第一次不像求救，而像提交戰報；高塔期用風聲、燈火、黯淡陣光與最後一夜的軍旗／黑甲私軍累積沉默壓力。 |
| 最終輪迴 | 分配時機、信任與風險。 | 不再追求自己被相信，而是讓每個人只知道當下該知道的，也先保護莉娜這類會被流程吞掉的小節點。 | 語氣平靜，每句話都帶著「現在還不能說全部」的重量；收服賽拉斯時先給可核對碎片，再碰密令與眼淚。 |

## 角色弧線

| 階段 | 心態 | 行動模式 |
|---|---|---|
| 序章（Loop 0） | 等待被拯救的公主 | 被動等待 → 死於無知。**濾鏡 1：保護者=行刑者** |
| Loop 1 | 恐懼、求助、開始觀察 | 從信任宰相到確認宰相是敵人，學會觀察人、隱藏情緒與修正判斷 |
| Loop 2 | 求證、偽裝、滲透 | 從下城區苦難切入，發現監視網與被操控的敘事，開始學會在錯誤視線裡生存 |
| Loop 3 | 冰冷、逼近真相、錯判 | 接觸地下防線、糧倉、達爾與城內核心問題，因理解不完整卻過早出手而失敗 |
| 最終輪迴 | 不再等人來救，也不再單打獨鬥 | 整合同盟、民心、技術與證據，同時處理兵、民、術、證，主動打破輪迴 |

## 策略摘要

- 艾蓮娜的成長不是從弱變強，而是從只會依賴單一路徑，變成會同時處理多條路徑。
- 她最初用信任求生，後來用懷疑求生，最後用整合求生。
- 她每次死亡都在修正自己對世界的讀法，也在修正自己出手的順序。
- 她真正的策略能力來自輪迴後的比較：知道哪種說法會害死人，哪種時機不能先碰，哪條線必須同時動。

## 她對外出的誤解與修正

初期艾蓮娜以為「莉娜在身邊」就是安全，以為自己看過外城邊界代表那條路本來就能走。她不知道真正保護她的是看不見的暗衛、清場、門禁名冊、固定回宮路線與禁衛責任。

B 線三輪修正的是這個誤解：

- B-0：她把順利誤讀成莉娜知道路，實際上是宰相撤換保護後放她進陷阱。
- B-1：她借用王室慈善／禮儀名目，發現正常流程也能被接管成展示與監視。
- B-2：她理解路本身已被打開，於是沿同一路數反向偏離；這不是逃宮，而是把陷阱當成臨時通道使用。

## 終章的勢力判斷

終章的艾蓮娜最重要的成熟，不是「知道宰相是壞人」，而是能把不同性質的敵對力量分開處理。

- 對鄰國軍事威嚇：她承認父王與賽拉斯面對的壓力是真的，不把備戰簡化成暴政。
- 對宰相私軍／叛軍：她不嘗試說服，而是交給證據、封鎖、斷補給與賽拉斯的收網。
- 對被動員暴民：她不把他們寫成敵人，而是先送到糧藥、讓布魯諾能查證，再把怒火轉向真正掠奪者。

這使她不再是單線揭發者，而是能同時處理外患、內賊、民怨與話語權的繼承者。

## 她真正想保護的東西

- 自己不要再作為無知的祭品死去。
- 父王、賽拉斯、下城區和平民之間不要再彼此誤解。
- 王國不要只靠犧牲與沉默苟延殘喘。

## 她最大的盲點

- 初期太容易把第一個願意聽自己說話的人當成依靠。
- 中期太想立刻修正世界，反而會在理解不完整時過快出手。
- 她必須學會：真相本身不會自動救人，還要有人、時機與證據一起到位。

## 章節寫作規格

| 章節 | 對外說話方式 | 內在判斷方式 | 出手方式 |
|---|---|---|---|
| 序章（Loop 0） | 問句多、會先請求允許，習慣把判斷交給大人 | 以「誰對我溫柔」判斷可信度 | 等待、依賴、被動承受 |
| Loop 1 | 開始用短句試探，說出口的比心裡少 | 會比對表情、語氣、重複出現的細節 | 想抓單一突破口，先確認誰是敵人 |
| Loop 2 | 表面更柔順，必要時主動配合他人期待 | 開始區分真苦難與被安排的說法 | 偽裝、滲透、在監視網裡借力使力 |
| Loop 3 | 句子更短、更冷，少求安慰也少解釋 | 從看人轉向看流程、時機與系統 | 想同時搬動多條線，卻因太急而失手 |
| 最終輪迴 | 平靜、精準、每句話都帶任務 | 先想誰該現在知道，誰要晚一點知道 | 同步調度兵、民、術、證，不再單打獨鬥 |

## 對白抓法

- 她前期不是聰明地反問，而是真心不知道，所以問題會帶一點依賴感。
- 她進入 Loop 1 後，開始把真正想問的東西藏在次要問題裡，像是在試水溫。
- 到 Loop 2，她的嘴上話和心裡話會明顯分離；表面可以柔順，內心其實在記錄誰的答案不自然。
- Loop 3 的她講話更像在確認流程，不再期待單靠坦白就換來信任。
- 最終輪迴的她一句話只做一件事：安撫、下令、交換、確認，幾乎不浪費語句。

## 真正成為棋手的判斷點

- 不是她第一次認出宰相時。
- 不是她第一次拿到完整真相時。
- 而是她終於知道：真相若只握在自己手裡，只會讓知情者一個一個死去，所以她必須安排揭露順序、分配風險與責任。

## 分輪心理與決策表

| 輪次 | 看見什麼 | 當下怎麼想 | 做出什麼決策 | 合理性驗證 | 寫作禁區 |
|---|---|---|---|---|---|
| LOOP 0 | 火光、城破、賽拉斯帶血進房 | 保護者終於來了，卻說父王已死 | 先求救、追問、被動承受 | 她沒有任何情報，只能依賴熟悉的保護者 | 不要讓她在序章就冷靜分析陰謀 |
| A-0 | 重置日常、莉娜、宰相項鍊 | 賽拉斯殺過我，宰相才像能聽我說話的大人 | 找宰相求助 | 極端恐懼中抓住最溫柔的大人合理 | 不要讓她立刻斷定宰相是主謀 |
| A-1 | 茶味與道歉仍在，賽拉斯哭過 | 宰相危險，但賽拉斯的哭代表他不是純敵人 | 質問賽拉斯、觀察表情 | 她開始用死亡細節推理合理 | 不要讓她已經懂得隱藏觀察 |
| A-2 | 賽拉斯說只有王知道更多 | 最高權力應能阻止宰相 | 走明路求見父王 | 她已有敵人與毒茶線索，但無證據鏈 | 不要讓父王立刻採信並翻盤 |
| B-0 | 下城區痛苦與莉娜的舊路印象 | 高位路線不能走，身邊善意或許能帶她看真相 | 請莉娜幫忙靠近外城門 | 她不知道外出保護網，因此誤判合理 | 不要寫成莉娜真的有能力帶她自由離宮 |
| B-1 | 異常會被抓、戴項鍊後流程變順 | 只要演成正常公主，也許能安全觀察 | 偽裝順從、借禮儀／慈善流程外出 | 這是對 A-1/B-0 的合理修正 | 不要讓她看見的是完全未加工真相 |
| B-2 | 展示路線、口頭線索、密道影子 | 紙面會害人，身體記路比較安全 | 偏離路線、靠近物理破口 | 她知道路已被打開，反向利用陷阱合理 | 不要讓她沒有保護也能安全帶出鐵證 |
| C-0/C-1 | 陣區、達爾、助手、維護鏈 | 問對問題或提前告知就能救人 | 默背節點、預警達爾、嘗試匿名 | 她一步步修正前一輪失敗合理 | 不要讓匿名自動保護知情者 |
| C-2 | 父王會聽，但會囚禁她；高塔半年裡下城區、軍務與技術線仍未被接住；最後一夜看見鄰國軍與宰相私軍接上 | 完整交牌給王權仍不等於終局，抓出宰相也不等於修好被他拆散的系統；外患、私軍、暴民不是同一股力量 | 主動以冷茶結束輪迴，心裡定下「下一次我要發牌」 | 她第一次奪回死亡主動權，心理門檻成立；冷茶承載半年頓悟與最後拼圖 | 不要把冷茶寫成投降或絕望自棄 |
| 最終輪迴 | 所有失敗的反制規律 | 不是要被相信，而是分配誰何時知道，並先把弱者從洩密節點挪開 | 同步調度兵、民、術、證；先用可核對碎片打開賽拉斯，再用密令與理解收服他 | 她把已獲情報轉成時機表，終於合理成功 | 不要讓她變成無情全知的天才 |

## 不要寫成什麼

- 不要把她寫成一開始就很會布局的天才少女。
- 不要把她後期的冷靜寫成刻薄或傲慢；那是疲憊後的節制。
- 不要讓她在最終輪迴變成沒有感情的機器，她只是終於知道感情該放在哪個時機表達。
