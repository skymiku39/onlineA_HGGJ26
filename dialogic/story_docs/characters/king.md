# 國王（King）

| 項目 | 說明 |
|---|---|
| 年齡 | 48 歲 |
| 角色定位 | 缺席的父親。他的每一個決定都是為了保護城市和女兒，但代價是讓所有人誤解他 |
| 核心衝突 | 「朕不知道叛徒是誰，但朕知道叛徒存在」——所以他選擇犧牲名譽秘密備戰，而非打草驚蛇 |

## 表情組

`default`（威嚴）

## 目標

**個人目標（角色主觀）：**

- 在不驚動朝中內應與鄰國的前提下，秘密完成備戰。
- 保住王國、防線與公主，即使代價是讓自己被誤解成暴君。
- 若最壞情況發生，至少不要讓公主落入敵軍或叛徒手中。

**劇情目標（故事功能）：**

- 作為「善意加害者」，讓玩家理解保護也可能因沉默而變成傷害。
- 提供王國真實外患的重量，使故事不是單純宮廷陰謀，而是內憂外患互相咬合。
- 在終章成為公主必須重新接上的王權與合法性節點。

## 每輪對公主變化的反應

> 國王的深度在於：他不是不信女兒，而是永遠被迫同時作為父親與國王反應。父親會先被觸動，國王會立刻把觸動壓回程序、保密與風險控管。

| 輪次 | 他看見的公主 | 誤讀／防衛 | 被觸動與演出 |
|---|---|---|---|
| LOOP 0 | 不可察覺；他已在南門戰死。 | 死前仍相信隔離與密令是最後保護。 | 只能透過密令回看他的恐懼。 |
| A-0 | 未有效接觸。 | 不變，仍把她排除在秘密備戰外。 | 缺席要像一堵牆，讓宰相更像可依靠的大人。 |
| A-1 | 間接聽聞公主不安。 | 誤讀為壓力、噩夢或宮中流言。 | 若被提到，應先皺眉而不是憤怒。 |
| A-2 | 她說出不該知道的碎片。 | 父親想相信，國王立刻判斷她已成為破口，選擇隔離。 | 手停住、眼神軟一下，下一句卻變成命令。 |
| B-0 | 她擅自離開安全範圍，但他未必立刻知道保護網已被人動過。 | 誤讀為任性與危險，防衛是保護性關押；真正的問題是正常暗衛與門禁被撤換。 | 怒氣要帶恐懼，不是單純威權；他罵她時其實在怕自己保護失效。 |
| B-1/B-2 | 多半不可直接察覺，只會在事後看見外出流程或護衛名冊異常。 | 不變，繼續秘密備戰；他太晚意識到「名義正當的保護流程」也能被宰相偷走。 | 他越缺席，玩家越容易誤會他冷血。 |
| C-0/C-1 | 未同步收到完整技術真相。 | 制度雜訊蓋過她的行動意義。 | 可透過延遲批示與禁令表現被隔開。 |
| C-2 | 她像帶著戰報來的人。 | 父親相信，國王不能立刻公開採信；防衛是高塔隔離與查證。 | 要寫出他最痛的是：相信她，卻仍親手關住她。 |
| 最終輪迴 | 她不求立刻被相信，而給出可查證順序。 | 初始仍防衛，懷疑她是否被利用。 | 當證據順序逐一對上，愧疚才浮出來；不要太早崩潰。 |

## 關鍵設計

國王不直接出現在公主面前（直到最終輪迴的朝堂對質），但他的影響無處不在：徵兵令是他下的，稅是他加的，密令是他給的，地下防線是他建的。他是整個故事中最大的「善意加害者」。

他給賽拉斯的密令——在城破時殺死公主——不是冷酷，而是不願讓女兒落入敵手。他知道這道命令有多殘忍，他也知道賽拉斯會多麼痛苦。但他別無選擇。

## 真實外患與被污染的情報

國王的壓力不是假的。鄰國確實在集結軍隊，邊境斥候與補給調動也確實異常；他選擇秘密備戰，是因為公開備戰可能讓敵國提前入侵，也可能驚動朝中內應。

他的悲劇在於：真實外患被莫里昂加工過。宰相私軍／叛軍製造假襲擊、污染補給與邊境情報，讓每個「看起來應該加強防衛」的決策，都同時變成民眾眼中的壓迫證據。國王不是愚蠢，而是被迫在真威脅與假脈絡混在一起的棋盤上決策。

## 策略摘要

- 國王的策略核心是「少數知情、秘密備戰、拖到能反擊的那一天」。
- 他寧可讓所有人誤解自己，也不願讓叛徒確定自己已被鎖定。
- 他會優先保全國家結構，再處理私人情感，因此看起來像冷酷的父親。
- 他知道鄰國威嚇是真的，但不知道宰相已經用私軍把威嚇加工成內亂。
- 他的失敗不在於不夠愛，而在於把沉默當成了萬用的保護。

## 他真正想保護的東西

- 王國不要在毫無準備下被一擊毀滅。
- 公主不要成為叛徒或敵軍的人質。
- 即使魔法陣失守，城市也還有最後一條物理防線。

## 他最大的盲點

- 他低估了叛徒操控敘事的速度。
- 他低估了人民長期被蒙在鼓裡後會產生的反作用力。
- 他低估了公主在痛苦中成長的速度與能力。

## 玩家感知弧線

| 輪迴 | 玩家對國王的印象 |
|---|---|
| Loop 0–1 | 缺席、冷漠、壓迫人民的暴君（宰相的形象塑造） |
| Loop 2 | 間接加害者——徵兵、加稅、鎖糧倉 |
| Loop 3 | 開始懷疑，但仍無法確定他是善意還是惡意 |
| 最終輪迴 | 真相揭曉：他知道叛徒存在，選擇用犧牲自己名聲換取城市存活的機會 |
