# 國王（King）

| 項目 | 說明 |
|---|---|
| 年齡 | 48 歲 |
| 角色定位 | 缺席的父親。他的每一個決定都是為了保護城市和女兒，但代價是讓所有人誤解他 |
| 核心衝突 | 「朕知道叛徒存在，但從未懷疑是宰相」——宰相是稀薄直系血脈的親族，若他退位或身亡，宰相便具備繼承資格；他以為血脈讓兩人站在同一邊，卻沒有排查最近的人。戰事已持續一段時間，城堡兵力大量外派支援前線貴族領地，對公主的說詞是「清剿小毛賊」 |

## 表情組

`default`（威嚴）

## 目標

**個人目標（角色主觀）：**

- 在不驚動朝中內應與鄰國的前提下，秘密完成備戰。
- 保住王國、防線與公主，即使代價是讓自己被誤解成暴君。
- 若最壞情況發生，至少不要讓公主落入敵軍或叛徒手中。

**劇情目標（故事功能）：**

- 作為「善意加害者」，讓玩家理解保護也可能因沉默而變成傷害。
- 提供王國真實外患的重量，使故事不是單純宮廷陰謀，而是內憂外患互相咬合。
- 在終章成為公主必須重新接上的王權與合法性節點。

## 三層目標解析

**表層目標（他自己知道的）**

在不驚動叛徒的前提下秘密備戰，讓城市活到能反擊的那一天。他知道叛徒就在旁邊，所以每一個決策都只能讓最少的人知道。

**核心策略（他真正在操作的）**

他用沉默保護秘密，讓自己被誤解成暴君——但他也用沉默逃避女兒。他推行中央集權、徵糧、重稅，這些決策確實傷到了一些百姓：不是宰相虛構的傷，而是他自己選擇的代價，因為沒有辦法兩全其美。他無法解釋，所以他選擇不解釋，也選擇不看——因為一旦真的看見她，就必須同時看見那些代價，以及他從未打算承認的那份逃避。

他把調查叛徒的視線往外看，從未懷疑過宰相：宰相是血脈上最近的親族，若他倒下，宰相便是合法繼承人之一。他以為這份利益綑綁讓宰相沒有叛變的理由，卻沒想到那在宰相眼中從一開始就是動機而非枷鎖。

戰事已持續一段時間。城堡裡原本駐紮的士兵大多陸續被調派出去，支援前線貴族領地的防守——因為貴族遲遲不願主動出兵，王國只能用僅剩的力量去頂。他對公主的說詞是城外有小毛賊需要清理，一個聽起來輕鬆的理由，用來遮住城防本身已比任何人對外承認的都要脆弱的現實。

**本質欲望（他從不說出口的）**

他希望女兒不必知道那些選擇有多難——但他也害怕，有一天她全部知道了，卻還是能理解他。那比被誤解更難承受，因為那意味著他親手教會了她，什麼叫做為了大局讓人受苦。他保護她，也在保護自己不必面對她。

他最不敢碰觸的是：他不是她口中那個聖潔的君王。他對百姓做過的事，有些是宰相捏造的，有些是他自己選擇的。他讓她繼續相信那個形象，因為一旦她不再相信，他就必須同時承認自己是誰。

## 每輪對公主變化的反應

> 國王的深度在於：他不是不信女兒，而是永遠被迫同時作為父親與國王反應。父親會先被觸動，國王會立刻把觸動壓回程序、保密與風險控管。

| 輪次 | 他看見的公主 | 誤讀／防衛 | 被觸動與演出 |
|---|---|---|---|
| LOOP 0 | 不可察覺；他已在南門戰死。 | 死前仍相信隔離與密令是最後保護。 | 只能透過密令回看他的恐懼。 |
| A-0 | 未有效接觸。 | 不變，仍把她排除在秘密備戰外。 | 缺席要像一堵牆，讓宰相更像可依靠的大人。 |
| A-1 | 間接聽聞公主不安。 | 誤讀為壓力、噩夢或宮中流言。 | 若被提到，應先皺眉而不是憤怒。 |
| A-2 | 她說出不該知道的碎片。 | 父親想相信，國王立刻判斷她已成為破口，選擇隔離。 | 手停住、眼神軟一下，下一句卻變成命令。 |
| B-0 | 她擅自離開安全範圍，但他未必立刻知道保護網已被人動過。 | 誤讀為任性與危險，防衛是保護性關押；真正的問題是正常暗衛與門禁被撤換。 | 怒氣要帶恐懼，不是單純威權；他罵她時其實在怕自己保護失效。 |
| B-1/B-2 | 多半不可直接察覺，只會在事後看見外出流程或護衛名冊異常。 | 不變，繼續秘密備戰；他太晚意識到「名義正當的保護流程」也能被宰相偷走。 | 他越缺席，玩家越容易誤會他冷血。 |
| C-0/C-1 | 未同步收到完整技術真相。 | 制度雜訊蓋過她的行動意義。 | 可透過延遲批示與禁令表現被隔開。 |
| C-2 | 她像帶著戰報來的人。 | 父親相信，國王不能立刻公開採信；防衛是高塔隔離與查證。 | 要寫出他最痛的是：相信她，卻仍親手關住她。 |
| 最終輪迴 | 她不求立刻被相信，而給出可查證順序。 | 初始仍防衛，懷疑她是否被利用。 | 當證據順序逐一對上，愧疚才浮出來；不要太早崩潰。 |

## 關鍵設計

國王多數時間不直接出現在公主面前，因為他被戰情、密室會議與保護性隔離邏輯包住。A-2 與 C-2 可以直接面見父王，但那兩次都只證明「父親願意相信她，國王卻不能立刻採信她」；直到終章朝堂，公主才用可核對資訊與同步盟友重新接上王權合法性。

他給賽拉斯的密令——在城破時殺死公主——不是冷酷，而是不願讓女兒落入敵手。他知道這道命令有多殘忍，他也知道賽拉斯會多麼痛苦。但他別無選擇。

## 真實外患與被污染的情報

國王的壓力不是假的。鄰國確實在集結軍隊，邊境斥候與補給調動也確實異常；他選擇秘密備戰，是因為公開備戰可能讓敵國提前入侵，也可能驚動朝中內應。

這場戰事已不是剛起頭的緊繃。前線消耗持續了一段時間，城堡常備兵力被分批調往前線，支援遲遲不肯主動出兵的貴族領地。城堡內的守備實際上已遠比外表看起來薄弱。他不讓公主知道這件事——對她說的是城外有小毛賊需要清理，一個能讓她繼續相信王國尚未到危急程度的說詞。

他的悲劇在於：真實外患被莫里昂加工過。宰相私軍／叛軍製造假襲擊、污染補給與邊境情報，讓每個「看起來應該加強防衛」的決策，都同時變成民眾眼中的壓迫證據。國王不是愚蠢，而是被迫在真威脅與假脈絡混在一起的棋盤上決策——而他最信任的內部節點，正是設局的人。

## 對保護網被偷走的盲點

國王確實設下了公主的保護網：外出要有正當行程、門禁名冊、護衛名冊、暗衛、回宮路線與可追溯責任。問題是，莫里昂偷走的不是「國王同意公主涉險」這件事，而是那些看起來仍然正常的流程。

因此 B 線裡國王不會第一時間看出公主被放進陷阱。他事後看到的可能是一份看似正當的慈善／禮儀行程、一組完整名冊、一條有簽核的路線，以及一堆因真實外患而不得不優先處理的戰情報告。這讓他的憤怒更合理也更悲劇：他以為自己在處理公主任性，實際上是保護系統已被人從內部換掉。

## 策略摘要

- 國王的策略核心是「少數知情、秘密備戰、拖到能反擊的那一天」。
- 他寧可讓所有人誤解自己，也不願讓叛徒確定自己已被鎖定。
- 他會優先保全國家結構，再處理私人情感，因此看起來像冷酷的父親。
- 他知道鄰國威嚇是真的，但不知道宰相已經用私軍把威嚇加工成內亂。
- 他的失敗不在於不夠愛，而在於把沉默當成了萬用的保護。

## 他真正想保護的東西

- 王國不要在毫無準備下被一擊毀滅。
- 公主不要成為叛徒或敵軍的人質。
- 即使魔法陣失守，城市也還有最後一條物理防線。

## 他最大的盲點

- 他從未懷疑宰相——以為血脈讓兩人有共同的保城動機，卻沒想到那份「共同利益」在宰相眼中從一開始就是動機而非枷鎖。
- 他用「小毛賊」的謊言掩蓋了城堡兵力已薄弱的現實，讓公主無法理解自己的保護網為什麼那麼脆弱。
- 他低估了叛徒操控敘事的速度。
- 他低估了人民長期被蒙在鼓裡後會產生的反作用力。
- 他低估了公主在痛苦中成長的速度與能力。

## 玩家感知弧線

| 輪迴 | 玩家對國王的印象 |
|---|---|
| Loop 0–1 | 缺席、冷漠、壓迫人民的暴君（宰相的形象塑造） |
| Loop 2 | 間接加害者——徵兵、加稅、鎖糧倉 |
| Loop 3 | 開始懷疑，但仍無法確定他是善意還是惡意 |
| 最終輪迴 | 真相揭曉：他知道叛徒存在，選擇用犧牲自己名聲換取城市存活的機會 |
