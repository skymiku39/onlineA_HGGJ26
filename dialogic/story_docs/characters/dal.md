# 宮廷陣防工匠 達爾（Court Array Craftsman Dal）

| 項目 | 說明 |
|---|---|
| 年齡 | 67 歲 |
| 勢力歸屬 | 知曉真相的技術官 |
| 角色定位 | 破局的鑰匙。唯一能把地下防線、魔法陣維護與可複驗修復串起來的人 |
| 口癖/語氣 | 慢條斯理，用工程比喻說話。不直接回答問題，需要公主用正確術語與正確問題去「敲門」 |
| 核心衝突 | 幫國王秘密修建地下防禦設施的總工匠，也是宮廷陣防維護的老技術官。他知道備戰與陣式結構，卻被宰相透過維護鏈、副手與程序層層包住 |

## 表情組

`default`（平靜）、`wary`（警戒）、`sad_smile`（悲傷的微笑）

## 目標

**個人目標（角色主觀）：**

- 活下去，不讓自己的專業變成宰相嫁禍與滅口的把柄。
- 把地下防線、陣式維護與維護鏈污染的真相交給真正能承擔後果的人。
- 在最後一次仍能用自己的專業保護這座城，即使他身邊的副手與程序已被滲透。

**劇情目標（故事功能）：**

- 作為技術真相與王權秘密的鑰匙，補上公主單靠政治與民心無法完成的「術」線。
- 讓公主理解：正確答案若沒有保護、程序與時機，會害死知道答案的人。
- 在終章提供可複驗的技術證詞，使宰相不能再把修復剪輯成破壞。

## 每輪對公主變化的反應

> 達爾不是方便的真相出口。他的第一層防衛是技術門檻，第二層防衛是程序恐懼：沒有正式保護的真相只會讓知情者被切成「擅闖陣區」或「破壞陣核」。公主要從「公主身份」進步到「問對問題且安排保護」才真的能接上他。

| 輪次 | 他看見的公主 | 誤讀／防衛 | 被觸動與演出 |
|---|---|---|---|
| LOOP 0 | 不可察覺。 | 不變，仍是被埋沒的技術真相。 | 只留下魔法陣被破壞的影子。 |
| A 線 | 不可察覺。 | 不變。 | 不出場。 |
| B-0 | 可能只聽到公主出現在下城區。 | 判斷她只是被安排看見苦難的王室孩子。 | 不主動出場。 |
| B-1 | 她以王室教育／城防旁聽名義接觸。 | 用術語與技術門檻防衛，不讓身份替代能力。 | 對她冷淡，但記住她問過。 |
| B-2 | 她帶著正確路線異常與術式疑點靠近。 | 仍不信任，只承認她不是完全空想。 | 壓低聲音，先問她從哪裡知道。 |
| C-0 | 她問到了真正的門。 | 用更高問題測她，確認她不是背台詞。 | 從不耐煩變沉默審視，第一次把她當學生。 |
| C-1 | 她提前警告且要求匿名匯報。 | 追問來源，因為太精準本身就危險。 | 被觸動的是她用技術證據請他履職，而非命令他相信。 |
| C-2 | 她把他或他的證詞放進王權線。 | 若沒有保護機制，仍會害怕成為單點證人。 | 不應安心，應更沉重。 |
| 最終輪迴 | 她帶著正確問題、正確時機與保護機制。 | 初始仍防衛，因為他知道真相會殺人。 | 被觸動的是她不把他當答案提款機，而把他放在可複驗的位置。 |

## 關鍵設計

達爾不是被藏起來的答案，而是仍在體制內工作的技術節點。這讓 C 線成立：公主可以用王室教育、城防旁聽與卷宗調閱的名目接近他，但她不能直接命令他交出核心技術。宰相不需要立刻殺他，只要讓副手、維護日誌、清場令與茶水都在自己掌控下，達爾越接近真相，越容易被剪成「失職」或「破壞者」。

## 行為軌跡

| 時間點 | 行為 |
|---|---|
| Day 1 前 | 完成地下防線驗收，向國王交付啟動方法 |
| Day 45（Month 2） | 維護鏈被宰相一方進一步接管，副手開始固定貼近達爾的課程、巡視與工作室 |
| Month 3-5 | 以宮廷陣防老工匠身分授課、巡視與修繕；表面正常，實際被程序和副手包圍 |
| Month 6 | 若公主沒有介入：魔法陣失效後，他被混亂吞沒，技術證詞失去作用。若公主接上保護機制：提供可複驗修復與地下防線啟動方法 |
