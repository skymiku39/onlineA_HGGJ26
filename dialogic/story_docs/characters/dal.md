# 盲眼老工匠 達爾（Blind Craftsman Dal）

| 項目 | 說明 |
|---|---|
| 年齡 | 67 歲 |
| 勢力歸屬 | 知曉真相的平民 |
| 角色定位 | 破局的鑰匙。唯一能告訴公主「國王真正在做什麼」的人 |
| 口癖/語氣 | 慢條斯理，用隱喻和比方說話。不直接回答問題，需要公主用正確的情報去「敲門」 |
| 核心衝突 | 幫國王秘密修建地下防禦設施的總工匠。工程完成後被莫里昂派人弄瞎雙眼滅口，僥倖活下來躲在下城區 |

## 表情組

`default`（平靜）、`wary`（警戒）、`sad_smile`（悲傷的微笑）

## 目標

**個人目標（角色主觀）：**

- 活下去，不再讓收留他的下城區居民因自己被牽連。
- 把地下防線、陣式維護與宰相滅口的真相交給真正能承擔後果的人。
- 在最後一次仍能用自己的專業保護這座城，即使他已失去雙眼與職位。

**劇情目標（故事功能）：**

- 作為技術真相與王權秘密的鑰匙，補上公主單靠政治與民心無法完成的「術」線。
- 讓公主理解：正確答案若沒有保護、程序與時機，會害死知道答案的人。
- 在終章提供可複驗的技術證詞，使宰相不能再把修復剪輯成破壞。

## 每輪對公主變化的反應

> 達爾不是方便的真相出口。他的第一層防衛是技術門檻，第二層防衛是恐懼：知道真相會害死收留他的人。公主要從「公主身份」進步到「問對問題且安排保護」才真的能接上他。

| 輪次 | 他看見的公主 | 誤讀／防衛 | 被觸動與演出 |
|---|---|---|---|
| LOOP 0 | 不可察覺。 | 不變，仍是被埋沒的技術真相。 | 只留下魔法陣被破壞的影子。 |
| A 線 | 不可察覺。 | 不變。 | 不出場。 |
| B-0 | 可能只聽到公主出現在下城區。 | 防衛是躲開，避免牽連收留者。 | 聽見「公主」二字停手，但不現身。 |
| B-1 | 若被接觸，先當她三分鐘熱度。 | 用術語與技術門檻防衛，不讓身份替代能力。 | 對她冷淡，但記住她問過。 |
| B-2 | 她若帶著正確口令或路線異常靠近。 | 仍不信任，只承認她不是完全空想。 | 退一步、壓低聲音，先問她從哪裡知道。 |
| C-0 | 她問到了真正的門。 | 用更高問題測她，確認她不是背台詞。 | 從不耐煩變沉默審視，第一次把她當學生。 |
| C-1 | 她提前警告且要求匿名匯報。 | 追問來源，因為太精準本身就危險。 | 被觸動的是她用技術證據請他履職，而非命令他相信。 |
| C-2 | 她把他或他的證詞放進王權線。 | 若沒有保護機制，仍會害怕成為單點證人。 | 不應安心，應更沉重。 |
| 最終輪迴 | 她帶著正確問題、正確時機與保護機制。 | 初始仍防衛，因為他知道真相會殺人。 | 被觸動的是她不把他當答案提款機，而把他放在可複驗的位置。 |

## 關鍵設計

達爾的眼睛就是被莫里昂弄瞎的——這個事實本身就是宰相叛國的物證。但達爾不會主動說出來，因為他怕連累收留他的窮人們。公主必須帶著足夠的情報，讓他相信「這個公主不一樣了」。

## 行為軌跡

| 時間點 | 行為 |
|---|---|
| Day 1 前 | 完成地下防線驗收，向國王交付啟動方法 |
| Day 45（Month 2） | 被莫里昂的手下弄瞎雙眼，躲入下城區東區廢井旁的廢墟 |
| Month 3–5 | 在廢墟中靠周圍窮人接濟生活，不見任何外人 |
| Month 6 | 若公主找到他：提供地下防線啟動方法。若無人找到：在城破之夜被瓦礫埋沒 |
