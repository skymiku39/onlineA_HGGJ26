## 1. 第一批必做背景

- [ ] `castle_corridor.png`
  - 用途：城堡走廊主背景
  - 目前暫代：`hallway.png`
  - 重點：王城秩序感、空曠、帶壓迫感

- [ ] `chancellor_study.png`
  - 用途：宰相書房、帳本與人證場景
  - 目前暫代：`hallway.png`
  - 重點：高級、整齊、可信任到可怕

- [ ] `lower_district.png`
  - 用途：下城區主背景
  - 目前暫代：`restaurant.png`
  - 重點：窮困、擁擠、真實苦難，不要畫成純廢墟

- [ ] `lower_district_safehouse.png`
  - 用途：B-0 被帶去喝茶的小屋
  - 目前暫代：`hallway2.png`
  - 重點：破屋、狹窄、不安

- [ ] `secret_passage.png`
  - 用途：密道 / 內牆通道
  - 目前暫代：`hallway2.png`
  - 重點：石牆厚重、隱蔽、像不該被看到的地方

- [ ] `dal_workshop.png`
  - 用途：達爾工作室
  - 目前暫代：`hallway.png`
  - 重點：工具、圖稿、修補痕跡很多，像真正工坊

- [ ] `throne_room.png`
  - 用途：最終揭露宰相的正式王座廳
  - 目前暫代：`throne_room_gj.png`
  - 重點：能撐起終局對質的氣勢

- [ ] `city_wall_dawn.png`
  - 用途：真結局破曉
  - 目前暫代：`window.png`
  - 重點：高處、晨光、解放感
